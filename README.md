# Gym-Buddy



# Features [MVP-0]

- Responsive Design accross phone(primary target), tablets, and laptops.

- Create a profile. [ Choose which data you want to public and which to keep private.(FOr competing with friends.) ]

    - Can set goals according to your targets.
    - Can moniter macros, total daily calories.
    - Will have a streak feature.
    - Access to all past data.


- Log Daily food intake [ Divided into breakfast, snack-1, lunch, snack-2, Dinner (Option to modify meal plan would be available.) ]

    - Would be able to log with text, voice or pictures.
    - Will be provided with macros breakdown and calorie tracker.
